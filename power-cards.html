Campaign home

This optional catalogue is not required for character creation or play: the builder already contains the comparison and selected cards. Use this page only when you want to browse all 215 Discipline powers from the VTM Wiki level 1–5 tables in one place or print a separate set.

How to use a power: name the power and your goal. Pay the listed cost. Roll the listed pool if one is given; use the opposing pool when the target resists. Apply the effect and note. “Free” means no Rouse Check. “Passive” means the power is normally always available. Power names follow the VTM Wiki. Blood Sorcery rituals and Oblivion ceremonies are separate systems and are not part of these level 1–5 choices.
